🌊 About Me

Hi! I'm Kunal Waghray — a full-stack developer based in Telangana, India, building web applications that are reliable, fast, and centered on the people who use them.

🧩 I turn ideas into thoughtful interfaces and systems that scale — and actually deliver value.
⚙️ My core stack is Ruby on Rails, JavaScript, and TypeScript.
🎯 I care about clean architecture, accessibility, performance, and maintainable code.
🚀 I take features end to end — from product thinking to deployment.
🛍️ Recently shipping across dashboards and e-commerce, iterating closely with designers.
